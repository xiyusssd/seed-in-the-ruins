## 每座庭院是一章

第一章「水还记得路」：在储水罐、管道与滤池组成的旧泵站中，把水慢慢还给土地。
第二章「给叶子一片天空」：在钢架、残留玻璃与封闭屋顶组成的废弃温室中，为一株植物找回阳光。
第三章「春天有许多种模样」：在有土壤种植床、外露根系与树冠地标的回生花园里，让不同植物相互照顾，决定把怎样的世界留给后来者。

每章都有独立开篇与收束；探索、机关操作和结局采用第一人称3D。电影风格画面与镜头推进组成的全屏序章讲述起点。美术参考《机器人总动员》中废弃工业环境与新生命并置的情绪，原创内容与CC0环境素材结合。
