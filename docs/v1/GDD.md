# 《废墟里的种子》可执行游戏策划

版本：0.1，2026-10-06。来源是用户提供的「送礼思路建议」对话；可读取的末条策划被缓存截断，本文将已取得的设定转成明确的可玩规则。

## 概念与主题

一份没有收件人的礼物，被留在废弃的 EDEN-04。漫游者循着生命信号来到城市，试图修复设施；最后才知道，研究员留下种子是为了恢复土地产生生命的能力。礼物只有被发现、理解和照料以后才成立。

标题：《废墟里的种子 / Seed in the Ruins》。主题填空：A Gift for the Abandoned World。赛道：Game。受众：喜欢环境叙事、轻解谜和生态题材的观众。目标体验时长10–15分钟，当前紧凑地图可能更短，尚未用首次试玩统计验证。

## 世界与叙事

EDEN-04 曾宣称能源全清洁、水全循环、农业高效。消耗随效率一起增长，维护、湿地和物种差异被压缩，城市逐渐超过承载能力。设施还在，但系统已经不能从损伤中恢复。

三层悬念依次回答：为什么没有居民；为何绿色设施仍然失败；种子究竟是谁留下、希望后来者做什么。终局协议为“不要重建 EDEN，让新的东西生长”。档案中所有比例和数据都是虚构剧情道具，不是现实环境研究结论。

## 地图与游玩顺序

入口 → 中央种子舱 → 三个任意顺序区域 → 南侧再生核心。无战斗、跳跃任务、复杂背包或死亡机制。

| 区域 | 交互内容 | 行为反馈 | 剧情功能 |
| --- | --- | --- | --- |
| 中央废墟 | 种子与记忆01–03 | 确认种子需求，开启修复 | 环保宣传与废弃物并置 |
| 水循环区 | 两段水路、记忆04–06 | 浑浊/清澈、池边植物、水声 | 高循环率掩盖污染与湿地缺失 |
| 能源区 | 五路负载、记忆07–09 | 广告开关、电流与风声 | 清洁能源仍受总供给限制 |
| 生物温室 | 六选三、记忆10–12 | 恢复小型植物群落 | 单一高产缺少恢复能力 |
| 再生核心 | 最后档案、两种结局 | 广告复亮或玻璃消失、植物生长 | 修复城市与恢复生命的区别 |

## 可执行规则

水路：每段有直通、过滤、湿地。必须连接“水源 → 过滤 → 湿地 → 蓄水池”。反向、重复或绕过过滤均失败。失败立即反馈并允许重试。

能源：供给100；广告30、居民档案25、商业区20、温室35、种子实验室30。必须保留温室和实验室，总需求不超过100。有效配置不唯一；保留居民档案，或保留广告、关闭其余非必需负载都可以。广告开关会立即改变世界和声音，玩家自己理解取舍。

生物：六种为高产谷物、豆科、地表覆盖、深根、花卉、速生作物。选择恰好三种，同时具备传粉者栖息地、深层取水、土壤保护。花卉+深根+豆科或花卉+深根+地表覆盖均可；纯产量组合失败。界面说明每种的生态功能，失败指出缺少的功能。

记忆：十二份，至少六份解锁核心；不要求全收集。档案保存在记忆册；重复读取不重复计数。离线重构与可选AI重构明确标示来源，想象性居民片段不作为新增剧情证据。

成长：三处每完成一处进入根、芽、叶的下一阶段。种子在中央可随时查看。修复不会因之后再试错误路线而回退。

## 两个结局

重启EDEN：灯和广告重新运行，种子仍在玻璃中，增长目标再次出现。不给玩家贴“坏结局”的标签。

释放再生：广告熄灭，保存玻璃消失，小范围植物在五秒内生长。城市骨架仍在，没有瞬间生成巨大森林。结尾是“你收到的不是一个世界，而是让世界再次生长的机会”。

通关后可继续搜集记忆、重返核心体验另一结局，或重开旅程。纪念卡显示结局、记忆数量和游玩时长，可保存PNG。

## 实现范围与软件

Godot 4.5、GDScript负责场景、碰撞、玩家、UI、状态和导出。Python标准库合成八个原创声音；FastAPI+Uvicorn负责可选本地AI服务；Noto Sans SC负责中文字体；FFmpeg将引擎直接录制的AVI转换成MP4。

第一版无需Blender、Figma或图像软件：几何体、材质和界面均可编辑源码，避免软件安装成为阻塞。后续美术可用Blender制作种子舱和区域设施，以glTF替换网格并保留现有碰撞与交互数据。

本版已实现完整玩法、两结局、保存、音频、卡片和AI回退。精细美术、真实提供商API验证、Windows真机测试和首次玩家可理解性测试仍待完成，不能用自动测试替代这些验收。
