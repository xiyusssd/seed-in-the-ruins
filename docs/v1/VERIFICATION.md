# 实际验证与局限

日期：2026-10-06，北京时间。开发与图形验证在本机Apple M5/macOS，Godot 4.5 stable、OpenGL Compatibility执行。

## 已执行

- Godot导入所有脚本、字体和八种声音，实际启动3D场景。
- `game/tests/flow.tscn -- --test`通过28个断言，覆盖起始封锁、先发现种子、错误水路、正确水路、过载与缺失必要负载、两种有效能源分配、失败生态组合、两种有效生态组合、六份记忆门槛、重复记忆去重、四处终端物理射线可达、真实W键移动、地面碰撞、两结局的玻璃/广告/植物变化、存档读写、全部12份记忆和重新开始。
- `backend/test_service.py`通过6个测试，覆盖健康接口、离线记忆、非法输入、两结局、提供商超时回退、模拟成功AI输出。
- GUI模式真实渲染并检查中央废墟、菜单、水路、恢复后水池、温室、再生结局和纪念卡截图。
- 游戏内自动化未剪辑游览真实执行三谜题与再生结局，并由Godot直接录制含声音AVI；转码MP4，没有剪辑或生成虚假场景。
- GUI游览调用纪念卡保存逻辑，PNG保存在独立验证目录。
- macOS与Windows桌面导出；macOS从导出的.app包启动做运行检查。

完整日志保留在本地builds/目录；提交包附精简验证日志。测试采用独立verification.json。

## 仍未验证

- Windows电脑上的实际启动、图形驱动兼容性和输入体验。已交叉导出不等同于实机通过。
- 真实LLM提供商调用和实际生成内容质量；仅验证协议模拟与失败回退。
- 首次玩家能否无讲解通关、10–15分钟时长、叙事理解率。
- 1080p/60FPS目标未进行系统基准测试，不把录屏速度当成帧率成绩。
- 其他macOS机器的公证/下载启动体验；本机包为ad-hoc签名。
- 比赛账号、报名、上传、入口限制与有效提交回执。

## 已发现并修复

核心控制台一侧射线被外壳遮挡：交互体移到控制台中心，验证两侧接近的可达性。最初字体变量字重键类型错误导致太细：使用字体支持的OpenType数值标签。最初音频循环在自动退出时残留：改用原生WAV循环并在图形退出前停止与释放，headless测试不启动混音。最初macOS导出缺少Apple Silicon纹理导入设置：已启用ETC2/ASTC后成功导出。
