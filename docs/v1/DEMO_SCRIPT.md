# 五分钟现场演示

准备：插电，启动游戏，打开现场体验模式，开始新旅程；关闭AI后台也能演示完整流程。先解释WASD、E和鼠标，再让观众自己操作。

| 时间 | 画面与操作 | 讲述 |
| --- | --- | --- |
| 0:00–0:30 | 标题、进入废墟 | 礼物留在世界里，等待后来者完成它。 |
| 0:30–1:15 | 中央种子舱，读取附近记忆 | 城市的承诺与废弃物形成矛盾。 |
| 1:15–2:15 | 东侧能源台，关闭广告和商业区，应用调度 | 清洁能源仍然有限。把需求降下来，风才被听见。 |
| 2:15–3:00 | 返回种子舱，查看根 | 修复变成可见的生命，而不是分数。 |
| 3:00–4:20 | 演示其余区域，或播放附带完整游览录屏 | 水先过滤再进湿地；花卉、深根、豆科形成互补。 |
| 4:20–5:00 | 录像中的核心档案、再生结局和纪念卡 | 不要重建EDEN，让新的东西生长。 |

五分钟现场不保证第一次操作能完成全部关卡。需要展示最终结局时，使用已经通关的存档或公开附带的录屏，不声称现场跳过主线后的进度是完整人工试玩。

## 完整通关路线（供演示人员）

1. 广场中央种子舱按E，确认生长条件。
2. 中央三段记忆，西侧三段记忆，至少取得六段。
3. 西侧水路控制台：第一段过滤，第二段湿地，试运行。
4. 东侧能源台：关闭广告和旧商业区，留下居民档案、温室和种子实验室，共90。
5. 北侧温室：豆科、深根、花卉，模拟一季。
6. 南侧核心：阅读真相，释放再生计划。等待生长动画，保存纪念卡。
7. 继续探索；回到核心可以体验重启EDEN。

## 首次玩家验收

在不给答案的情况下让玩家完成主线。记录卡住的设施、首次理解控制方式的时间，以及结束后能否解释：城市为何失败、种子代表什么、为何只重建城市可能重复过去。当前没有进行这项真人验证。
