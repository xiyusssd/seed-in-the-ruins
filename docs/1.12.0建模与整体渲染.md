# 1.12.0：建模与整体渲染细化

温室在原屋架位置增加八榀带腹杆的工字钢桁架：上下翼缘、凹入腹板和两端封口均为实际网格。屋架节点有连接板与六角螺栓，柱脚贴合石基，边沟配两根落水管。新增结构位于高处或场地边缘，原入口、升降台、日光机关与开顶路径仍沿用原关卡。

回生花园增加纵向连续钢梁、柱脚、双向膝撑和横向拉杆；原石拱继续承担上层廊架。三处花床加入有缝分块石沿与端部封边，中央通行和操作位置保持原尺寸。第一章补齐泵站拱脚石、起拱处石块、分段檐口和管线固定件。

植物使用原叶脉图，在弯曲网格上增加左右不对称卷曲、叶柄方向旋转及长宽差异。叶色略提亮，逆光透叶效果加强。温室玻璃降低中央雨痕的不透明度，边缘积灰保留，粗糙度在干净区域与脏边之间变化。所有新增重复钢架、石材与紧固件采用 MultiMesh；没有新碰撞物或新的解谜状态。

W-01 的内向操作布局与九项任务的镜头聚焦继续保留；journey / puzzle v4 存档格式保持原值。模型与完整游戏仍有不同职责：models/1.12.0 保存三章静态环境，动态机关、维修结果和任务镜头由 game/garden.tscn 构建。

## 验证与产物

849 项功能检查，覆盖三章真实交互通关、行走与射线、W-01 入口可达、镜头归还及新增结构的网格端盖、凹入腹板、法线朝向、UV 和切线。Forward+ 与 OpenGL Compatibility 各 100 个完整画面，包含三章初始及完成状态、全套原镜头、两个新增屋架近景、九项维修的同镜头前后对照和实际 1/12 复色状态。实际栅格渲染同时检查每根梁是否准确接触其两个节点。

200 张完整实景来自 Godot 4.5 / Docker / Xvfb / Mesa 软件 Vulkan 与 OpenGL。三章原生模型从该批 Forward+ 场景导出并重新加载；16 张生成材质、开场图和音频继续核对原始指纹。macOS 检查原生场景构建、签名与 DMG；Windows 是交叉导出，未在 Windows 实机运行。既有 1.11.1 安装包及源码归档在 builds/releases/1.11.1。

新版本对照为 builds/render-comparison-1.12.0.html，完整图库为 builds/visual-board.html。此轮完成承重结构、细部材质和整体场景检查；功能平台的比例、摄影构图与植被丰富度仍与原开场 CG 有差异。固定立方体海面反射仍是位置近似，软件栅格检查也不能据此估计原生 GPU 帧率。
