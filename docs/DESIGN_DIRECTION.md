# 后续方向

依据最新用户要求，后续以完整三维第一人称项目为准：WASD连续探索、鼠标视角、近距离调查。开始整个世界黑白，每找到一条独立线索，整个世界恢复更多色彩。音乐保持空旷废墟氛围，并随恢复渐入温暖声部。

建筑、角色移动、机关、阶梯和升降保持真实三维坐标。界面提供当前行动、调查反馈和颜色恢复进度；菜单与线索阅读释放鼠标。颜色不会被重复线索刷取，也不会在换关和读档时丢失。

## 0.3.1：治愈废土与篇章

参考 Pixar《WALL·E》的环境情绪（https://www.pixar.com/wall-e）：旧设施保留使用痕迹，小生命带回希望。保留原创庭院与种子故事。低饱和锈橙、砂岩、鼠尾草绿与温暖天光构成恢复后的调色板。初始仍为全局黑白，不预先显示彩色线索。

石材采用程序噪声颜色与法线，拱门以独立砌块的接缝表现厚度；桥面有铺装与矮柱，远处有残柱与碎料堆。旧机械使用通风栅、锈蚀边条和独立支座；其上长出幼苗。装饰不阻挡已验证路线。复色同时降低雾密度、增加环境光和幼苗尺寸，屏幕只有轻微暗角，没有闪光或强晃动。

每章独立开篇：水还记得路、把天空打开、春天不是一个人。开篇在真实第一人称场景旁展示，可直接进入探索，原两种结局保留。

## 0.3.2：参考方案的第一轮实施

三章环境已改造为旧泵站、废弃温室、回生花园。第一章移除重复的装饰亭群，改为泵站立面、储罐和管道；第二章加入高温室框架与残留侧墙玻璃，保留足够的升降和行走空间；第三章加入土壤种植床、外露根系和树冠地标。装饰均不承担隐含可行走道路，既有路径与机关的碰撞保持验证。第一人称控制、十二条复色与两结局不变。
