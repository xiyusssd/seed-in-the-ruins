# 四轮渲染迭代 · 第4–7代

2026-10-07，基于旧城来信版连续实现四轮渲染改进。四轮结束时版本为0.7.0；继续优化后的当前桌面软件为0.8.0。仍为完整第一人称三维项目，三章、十二条线索复色、两个结局不变。

| 轮次 | 实现 | 从实际渲染中检查的重点 |
| --- | --- | --- |
| 第4代 / 0.4.0 | 调整太阳角度、暖光冷影、光照强度；4× MSAA、4096方向阴影与四级分割 | 阶梯明暗与边缘，避免过亮抹平石材层次 |
| 第5代 / 0.5.0 | 原创程序云层与太阳、近处细分水面和远处水面、细波法线、视角色调、基础周围浅色水纹 | 天水分层、慢速运动；浅色水纹为程序表现，不是物理水深或真实屏幕空间反射 |
| 第6代 / 0.6.0 | 箱体可见倒角、侧底面顶点明暗；旧金属的粗糙度与反光区别于石材；尺寸网格缓存 | 建筑边缘与阶梯体积；原箱体碰撞保留，装饰不影响路线 |
| 第7代 / 0.7.0 | 温和的暖亮部冷阴影调色、轻微植被摆动、稀疏飘尘 | 黑白与复色准确、界面可读，无强闪光或镜头抖动 |

每轮目录在 builds/render-iterations 下，保存实际引擎截图、完整渲染日志与 scripts/shaders/project 配置快照。快照不是带所有资产的独立游戏包；完整源码与最终可执行包在比赛材料包内。原版截图也已保留。比较页：builds/render-comparison.html。

第七代初次使用 CPU 粒子时，自动截图未能完成；移除粒子模拟，改成20个解析动画的轻量标牌微尘后，截图完整完成。最终快照仅记录修复后版本。未将失败运行当作验证证据。

最终重跑55项玩法检查通过；对实际截图做像素检查，开场RGB三通道一致，半彩与全彩的颜色差异递增。渲染兼容模式，不宣称使用SSAO、屏幕空间反射、体积雾或实时全局光照。视频录制的速度不代表正常试玩帧率；Windows仍待实机验证。

技术依据：[Godot渲染器](https://docs.godotengine.org/en/4.5/tutorials/rendering/renderers.html)、[环境选项](https://docs.godotengine.org/en/4.5/classes/class_environment.html)、[方向光](https://docs.godotengine.org/en/4.5/classes/class_directionallight3d.html)。

## 第8代 · 叶片与温室 / 0.8.0

花草与幼树改为有尖端、弯曲叶面和中脊的原创网格，错开枝叶方向与高度，替换原先球体叶片和圆锥幼树。装饰植物不参与碰撞与线索射线。拱门使用显式外向法线，减少砌块数量与缝隙宽度，使内弧、外弧和正面的受光一致。温室残留玻璃新增程序雨痕与边缘积尘，保持透明；未使用折射或屏幕空间反射。

本轮同样保存三章受控截图、0/50/100%复色截图与源码快照；更新最终软件、游览视频及对比页。

## 1.0 · 机器人与九个谜题

新增Forward+高画质（Metal本机验证）：SSAO、ACES、轻辉光、局部灯、反射探针与普通高度雾；Compatibility保留基础效果。程序天空针对线性色彩管线转换，完整复色仍通过全局后期。新增泵房、工作柜、实体模块、镜架与光束、植物实际种植显示、风塔和原创机器人。两种画质均有受控截图与源码快照；正常时钟性能数据见VERIFICATION.md和performance-*.json，未用电影录制速度估算帧率。

## 1.1 · 模型、字体与组件

细化芽芽镜头、外壳和履带，机关柜采用平滑圆角网格、螺栓与刻度，管道增加法兰。加入Noto Serif SC标题与故事字体、铜色机械面板和纸页组件；减弱辉光，保留清晰的第一人称机关近景。高画质与兼容画质快照分别在v11-detail与v11-compatible，包含新增伙伴、档案、提示和设置截图。

## 1.4 · 修复现场与废土渲染

增加泵站检修灯、水位管、湿润痕迹、温室接光圈与花园灌溉反馈；优化微表面、玻璃、接触阴影与局部灯光。原生截图与源码快照保存在render-iterations/v14-forward和v14-compatible。1.4温室镜头向内侧偏移以避开前景柱，历史比较为同场景对照，不宣称逐像素同视角。视觉板更新为1.4，游览电影明确保留为1.1历史。
