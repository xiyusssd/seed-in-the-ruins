# 1.8 全屏故事与新手泵站

故事为覆盖整个视口的手记，宽屏使用插画与正文并列的布局，小窗口改成上下排列并允许滚动。上一页固定左下、下一页固定右下、跳过固定右上。标题、摘要与正文有不同的字重和尺寸。叙事继续在水痕、叶影、踏板和花盆中留下线索，不提供机关答案。

开始与暂停菜单撤掉帮助入口，H不再打开解题帮助。第一章直接进入泵站现场，避免再叠一张章节说明。教学面板只说明当前正在学的控制；移动并转动视角后引导调查来信、读取入口记录，随后教E/F调档、转桥、水压观察与C伙伴协作。目标在视野内标记位置，在视野外给转向标记。操作反馈就地可读，不需先发现日志菜单。菜单打开时教学隐藏，暂停时不推进任务；第二章起撤去第一关教学。原有谜题、记录、伙伴实地行走和通关门槛仍有效，没有自动替玩家解题。

教程学习记录增加到现有v4存档，读取时只接受已知技能。旧存档兼容，新旅程清空教学记录。故事重读、设置与首次进入仍保护当前存档。

## 建模与渲染

住宅两侧改为实开的窗洞，补窗台、木框与玻璃；屋瓦改为弧形搭接陶瓦和单独脊瓦。相同住宅静态构件按网格与材质合批，透明玻璃和风动植物保持独立。原来的扫描岩岸和树枝UV修正继续使用。

混凝土使用三张已核验的PBR贴图和原生三向投影，保留表面污迹、法线和粗糙度细节，提高色调亮度。实验性的潮湿/苔色Shader在实景中出现黑纹，已经撤下，采用原生PBR处理压缩法线，材质对照保存在 `builds/render-iterations/v18-material-diagnostics`，被撤下的Shader保存在 `tools/experiments`。泵站罐体添加成组紧固件与竖向筋，温室补连接螺栓，平台边缘补不规则骨料与露出的钢筋，所有新增装饰均无碰撞。新细节用MultiMesh实例化，避免每颗螺栓增加单独绘制。

海面改成四组较低的涌浪和随风移动的不规则细浪，淡出亚像素法线细节。复核先排除近海与远海在波谷交叠的问题，改为129段边界匹配的外围远海网格，中心区域不再叠两层水面。随后阴影对照确认剩余细密条纹来自移动水面的自阴影，水面撤掉投影但仍接收岸上建筑阴影；日光阴影偏移恢复稳健值。毫米级铺装接缝撤掉单独投影，桥板与码头面留出垂直间距。水面仍为游戏化波浪与岸边泡沫，不是流体或物理水深模拟。

## 帧率与验证

默认帧率上限120，设置可切换60、120、144与不限，并可开关垂直同步；保持物理步进和基于时间的移动，不按渲染帧数决定移动速度。开启垂直同步时帧率也受显示器刷新率限制。提高上限不保证硬件达到对应帧率。

两种渲染器共102张实景截图通过复核，每种渲染器检查14256条初始/修复状态模型记录；源码指纹与捕获工程一致。完整检查覆盖两种渲染器的三章模型、初始和修复状态、全屏和小窗口故事、菜单和五个教学阶段。使用Docker/Xvfb中的Mesa软件Vulkan/OpenGL实际绘图，不弹出macOS检查窗口，不能作为原生Metal或Windows GPU帧率的证明。第一次未合格水面截图保留在 `builds/render-iterations/v18-first-pass`；最终图片位于 `builds/render-iterations/v18-final`。七套自动化测试合计502项检查通过，32份外部场景素材的运行时哈希保持一致。解谜测试检查实际操作流程，教学测试另通过真实移动、视角、调查、反向操作、物理转桥与机器人到位来完成第一章。

安装包为1.8.0独立app、macOS安装包、Windows交叉导出包和源码；1.7.1独立app保留，通用安装包归档到 `builds/v171`。Mac以headless方式校验场景、菜单、字体和环境声音，并验证签名与磁盘镜像；Windows仍待实机验证。
