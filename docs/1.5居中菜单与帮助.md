# 1.5 · 居中菜单与帮助

按照本次界面精简要求，探索画面删除标题、任务、色彩数字、伙伴状态、库存、键位、悬浮说明和反馈字幕。HUD只保留绘制的小准星与三线菜单图标，不创建文字标签。机关上删除教学句与C键说明；保留方向箭头、档位、水位、保险模块形状及必要种植线索，黑白状态仍可推理。

开始菜单与暂停菜单均居中，子页面同样居中。面板高度根据内容自然收缩，较小视口限制面板边界，长记录继续支持滚动。开始菜单可以先看帮助和设置，返回时保持未开始状态。

“帮助”集中提供WASD、鼠标、Shift、E/左键、F、Q、C、Tab、H和Esc操作。三级解谜提示保留在玩家主动请求的帮助子页。Esc从帮助/设置/物品返回菜单，再按Esc回到游戏；从标题打开的帮助或设置则回到标题。

随身物品在菜单中查看，三株种苗可用按钮直接选择，也保留Q循环选择与v4存档。最近八条不同反馈收进记录，最多展示最近三条；新旅程清空这份临时反馈。主动调查的故事、维护记录与结局保留。章末不会自动弹窗，下一章入口放在暂停菜单；帮助页对此有说明。

19项新增检查覆盖从标题访问帮助、返回与Esc导航、帮助键位覆盖、居中与较小视口、无文字HUD、反馈查阅、章末不弹窗、种苗选择及存读档。既有三章九谜题、真实准星、伙伴任务、可逆物件和两结局检查继续执行。当前版本的结果见VERIFICATION.md；不把1.4性能或1.1电影改标为1.5。
