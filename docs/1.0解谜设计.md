# 废墟里的种子 1.0 · 芽芽与环境解谜

当前版本从0.8.0的观景探索改为三章九个环境谜题。第一人称、十二条复色线索、三章故事和两个结局保留。30–45分钟是首次人工游玩的设计目标，尚无人工首次试玩时长数据；自动化通关知道答案，不能作为该时长的证据。

## 机关与推理

| 章节 | 规则 | 成果 |
| --- | --- | --- |
| 水路 | 三个接头出口依次为东、西、南；初始均朝北 | 水依次经过滤池、蓄水槽、回流；旁路漏水，解锁桥 |
| 水压 | 入水Ⅱ、回流Ⅰ；仪表为两倍入水减回流，应读Ⅲ | 稳定水位，允许派芽芽去踏板 |
| 水泵 | 芽芽实际到供电踏板保持电路，玩家到泵房启动 | 开放下一章 |
| 电源 | 模块架上圆、三角、方三个实体；槽位铭牌为方、圆、三角 | 日光台通电 |
| 日光 | 第一镜东向、第二镜西向；可见分段光束，中继后照幼苗 | 允许机器人保持制动 |
| 屋顶 | 芽芽守住高处制动，玩家在幼苗区开顶 | 屋顶移动，进入下一章 |
| 种植 | 西床访客、东床养分、北床深水；花、豆科、深根匹配 | 各床显示实际安装的植物 |
| 灌溉 | 西Ⅰ、东Ⅱ、北Ⅲ；分水器可重调 | 开放风塔阶梯 |
| 风塔 | 芽芽先去入口工具架取储能单元，再送往风塔；左接头南、右接头东，玩家启动 | 解锁保护罩/自由生长两种选择 |

规则以刻痕、方向、凹槽和文字表达，零饱和度下仍可推理。E拿取/安装/取回，交换物件不会丢失；每类物件一个手持槽。成功机关保持锁定，防止已完成成果被无意撤销；菜单可以重置本章，回到入口，物件和机器人复位，已获得的颜色不撤回。

每章只有一封环境来信可以直接发现；另外三封由解谜成果授予。结果石碑只是重读入口，不会绕过谜题。全局复色每条1/12、过渡2.4秒、去重、跨章和读档保留。

## 伙伴与操作

芽芽采用原创圆角维护机器人：单镜头、双履带、可动头部和机械臂，普通Godot节点构成，独立可编辑场景 `game/characters/yaya.tscn`。部件按待机、观察、跟随、操作、搬运和庆祝状态动画，不依赖外部角色资产。

C打开指令菜单，跟随/等待/协助。协作需要实际到装置旁；搬运先拿物件再送达。沿当前连通的节点路径走动，不参与玩家碰撞；跟随距离过远或卡住时，仅在玩家视野外恢复到安全停靠点。执行远距离任务时不会因离玩家远而取消运输。机关切换和升降可能让路径短暂不通，伙伴会重新规划；可召回并再次派遣。

玩家须亲自走近装置，用准星操作。桥梁只能在轮柄附近旋转，升降台需要玩家站上平台；交互不再自动走完整路线。H默认第一层提示，可主动展开到规则与具体下一步，层级按谜题独立记录。Tab重读来信，Esc暂停/设置/重置本章。菜单有滚动区域，长中文文本可阅读。

## 图像与声音

高画质为Forward+/Metal（本机），接触环境遮蔽、ACES色调映射、克制辉光、局部灯、一次更新反射探针、普通高度雾；兼容画质为Compatibility/OpenGL。渲染器切换保存旅程后重启，配置独立持久化。程序天空在两种色彩管线分别转换，黑白后期覆盖世界与UI。不使用强运动模糊、持续景深、实时GI、SSR或体积雾。

泵房围墙、工作柜、真实形状模块、镜架与光束、种植床、根系面板和风塔是可见的新机关场景。保留风化石材、原创水波、玻璃雨痕、弯曲叶片和稀疏微尘。

原创程序合成三章各两层16秒立体声音乐：工业低音与稀疏节奏、温室轻键音、花园木质柔和声部；暖声部按复色和解谜进度混合。九份新增机械/环境音，使用3D位置播放，另保留已有脚步、线索、成长等声音。Music/Effects/Ambience音频总线各有独立滑条，菜单暂停音频，短声冷却和并发上限防止叠加失控。

## 存档与交付

v4独立文件 `user://ruins-first-person-v4.json` 保存姿态、机关档位、物件、成果、伙伴任务与运输阶段；独立 `ruins-settings.json` 保存音量和画质。不读取或覆盖v3存档。0.8.0可运行软件与当时完整材料已留在 `builds/v8`。

自动化完整通关使用真实可达路线、距离验证、物理射线命中、E交互和C指令按钮，伙伴实际走动；没有直接写入已解谜状态。截图和性能测量另使用受控状态，明确标注，不作为通关证据。
