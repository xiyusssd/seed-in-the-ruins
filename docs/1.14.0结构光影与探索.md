# 1.14.0 · 结构、光影与探索

旋转桥增加两根纵梁、三道横肋和六根斜撑，位于踏板下方，不占用玩家通路。升降井上层残碑下增加固定钢制检修托架，并连接井架立柱；升降台不在上层时，井口仍不能站立。延续 1.13.1 的约 1.28 米路边残碑和侧向摆放。

残碑及机关柜采用实际网格碰撞。水压柜、维修灯和水位管一起移到平台东侧，操作面朝向平台中央，读数与阀门左右次序保持一致。平台移动按真实矩形地面的尺寸判断，保留玩家胶囊的边缘余量；斜向走到边缘时沿受支持的方向移动，碰撞修正若将玩家推出平台则撤销该次移动。关闭的旋转桥和空升降井仍不开放通路。

环境光略提高，调整日光角度、阴影偏移和局部 AO，让深处的梁架更清楚。锈钢的完整金属区保留反光，锈坑保持粗糙。桥面磨损钢材通过显式标记应用到圆角网格，修复此前按 BoxMesh 判断导致材质未生效的问题，三章统一使用。

设置增加鼠标灵敏度，范围为默认速度的 0.5–2 倍，立即生效并保存；原设置文件缺少此项时继续使用默认值。准星对准范围内的可操作对象时显示细金色圆环，减少寻找机关的试探。声音控制改为紧凑横排，保留原有设置并使整页可见。

后台验证使用独立存档。完整测试入口为 `tools/run_later_visibility_checks.py`，16 组共 1,182 项源码检查通过；新增探索测试检查实际地面、边缘滑行、碰撞、升降井和灵敏度保存。纹理检查在源码中核对原 PNG 的 SHA256，在导出应用中加载经过导入的纹理并核对原始尺寸，避免把正常的导出资源转换误判为文件丢失。`polish_render_review.tscn` 生成三章、黑白状态、机关操作及设置的 13 张真实渲染图。结构检查镜头用于看清梁架，不作为玩家可站立位置；水压操作近景随柜体移动调整朝向，其余前后对照使用同一镜头。

发布检查和画面报告在本地 `builds/`，源码与测试提交到独立 GitHub 仓库，不包含上级机器人训练工程、用户存档、导入缓存或旧版打包文件。GitHub Actions 使用校验过 SHA256 的 Godot 4.5 执行完整 headless 测试。现有游戏窗口与旧应用保留，新版由用户自行打开。
