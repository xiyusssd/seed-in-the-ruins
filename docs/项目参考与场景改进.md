# 项目参考与场景改进

2026-10-07。目标：第一人称 3D、治愈废土、三个独立篇章、十二条线索逐步恢复全世界颜色。

本次依据开发商与发行商的项目介绍、开发复盘进行研究；没有亲自试玩这些作品。下文“采用方式”为本项目设计判断；实施状态见文末，现有软件尚未具备所有规划效果。

## 当前版本的问题

现在三章都有铺装、拱门、柱廊和旧机械，但主要由同类平台与亭子重复构成。水面与空中平台占比过高；机器虽有锈迹，缺少前后的工作流程和周围生活痕迹。线索的故事主要通过弹窗呈现，玩家尚不能从现场看出足够的信息。改善方向是改变空间组织、功能与活动，而不只是继续增加材质噪声。

## 三章的场景方案

### 第一章：水还记得路 — 旧泵站

进入一段水位下降后的维修廊道，破损管线指向远处水塔。桥下积水、岸边沙土与旧滤池共同建立前中远景。四条线索分别放在工人工作台、河道改造图、废弃湿地牌、旧过滤器旁。修复机关后，水沿可见的渠道慢慢进入种植槽；第一批芦苇展开。章末留一个能够回头看修复结果的位置。

### 第二章：把天空打开 — 废弃温室

从有遮挡的检修入口走进半封闭温室。空间区别于第一章的开敞水岸：玻璃框架、旧遮阳板、废弃照明轨道与朝向裂缝生长的植物。四条线索围绕过量照明与真实日光。升降和开顶机关保持可玩功能，打开屋顶以后，光照位置发生变化，小叶子迎光展开。章末回望天窗。

### 第三章：春天不是一个人 — 回生花园

从混凝土与土壤交界处进入花园。重复花盆、破损培育槽与三处不同的小生境构成对比。远处种子树是最终地标，路径有台阶和坡度但没有强制跳跃。四条线索分别强调单一品种、微小生命、相互补足与后来者。最终恢复表现为不同植物共同生长，保留原有两个结局。

## 画面、交互与声音要求

- 保留全程第一人称与 WASD / 鼠标 / E。参考第三人称或横向游戏时，只采用场景和情绪方法。
- 初始全局黑白；每条独立线索仍恢复 1/12 色彩，重复调查不叠加，存档和换章保留。
- 各章使用同一个世界的材质语言：砂岩、旧金属、混凝土、少量玻璃与植被；不同章节改变遮挡、地形、尺度和功能。
- 首要目标可从场景中辨认，减少无处不在的金色圆环。附近可调查物仍有明确反馈。
- 废墟音乐保留空旷感；行动反馈用近处流水、旧金属、树叶和轻微生物声，不用强闪光或剧烈镜头抖动。
- 每章开篇、探索中的环境线索、机关修复、章末回望组成完整节奏。文字补充现场信息，避免承担全部叙事。

## 实施顺序与验收

先做第一章旧泵站作为视觉样板，验证正常眼睛高度下的路径、遮挡、尺度与回望构图，再把统一材质与交互语言扩展到另外两章。0.3.2 已实施第一轮空间重构：泵站立面、储水罐、管线与滤池；温室钢架、残留玻璃、育苗槽与旧灯架；回生花园种植床、外露根系、树冠地标与远处植被岛。保留既有路径和机关。章节全部转移到开敞土壤地形、增加水与植物动态等仍为后续计划。

验收：三章入口截图应能在不看标题时区分；机器的用途和修复结果应在现场可见；玩家能从地标判断方向；路径碰撞、台阶、机关、十二条线索与两个结局继续通过验证；黑白与全彩截图保持同一视角便于比较。之后重新导出软件并更新真实游戏内演示。
