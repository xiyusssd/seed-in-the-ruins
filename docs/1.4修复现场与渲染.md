# 1.4 · 修复现场与渲染

2026-10-08。三章九个谜题仍由真实距离、准星与操作完成，已有v4存档继续有效。

章节开篇改为“所在场景—正在修复什么—伙伴如何协作”；十二封来信增加修复档案，九个成果各有芽芽的短回应，重复操作不会重复触发成果对白。章节名称与主景对应为旧城泵站、日光温室、回生花园。

泵站补充检修灯、夹具、任务工牌与刻度玻璃水位管。水位管按净水位实时上升，先接通水路才显示水；水泵恢复后地面出现湿润痕迹。温室的中继板朝向入射光，接光标记与育苗台灯光反映光路；种植床在植物就位与分水器开通后出现灌溉水流。新增装饰没有碰撞，不改变必经通道，每章最多两盏无阴影局部灯。

Forward+接触阴影缩小半径与强度，天光及检修灯保持柔和。风化材质增加有距离衰减的微表面法线，玻璃增加边缘风化层；保留原有全局复色后期与Compatibility适配。NORMAL与VERTEX按片元视空间计算，参考[Godot 4.5空间着色器文档](https://docs.godotengine.org/en/4.5/tutorials/shaders/shader_reference/spatial_shader.html)。不启用持续景深或运动模糊。

几何中文标题、等宽读数和中文回退保持现有OFL字体。缩小机关读数以避免相邻控件重叠；靠近机关才展开诊断。顶部状态使用具体的水路、水压、水泵等任务，操作字幕与成果反馈分开。三章开篇与设置返回按钮均无需滚动。
