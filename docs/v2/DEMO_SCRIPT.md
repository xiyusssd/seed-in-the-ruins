# 第二版现场演示

## 五分钟结构

| 时间 | 实际操作与讲述 |
| --- | --- |
| 0:00–0:30 | 显示入口与小园丁：种子留在废墟里，等后来者完成这份礼物。 |
| 0:30–1:40 | 点击第一庭轮柄，看到园丁先走到桥边、长桥转90度，再走上高塔；打开水闸，看到瀑流与湿地生长。 |
| 1:40–2:50 | 第二庭升降台把角色从低处带到高处；转桥、进入温室、打开屋顶，让光抵达植物。 |
| 2:50–4:10 | 第三庭旋转枢纽，访问三种植物；表现互补而非追求单一最高产量。 |
| 4:10–5:00 | 最后手记、释放再生计划、旧塔周围出现植物，保存种子卡。 |

操作速度较慢时可先演示一庭，再展示附带真实录屏。不要声称自动录屏是第一次玩家不经讲解的通关证据。

## 全流程操作

第一庭：入口走到桥边，点击旁边轮柄，长桥对齐；点击高塔上层圆环或水闸，角色沿桥与台阶走过去，打开水。

第二庭：点击下层轮柄，角色走上升降台，平台上升。点击高层转桥轮柄，桥对齐后进入右侧温室，点击屋顶轮柄。可用高层升降轮柄返回低处。

第三庭：进入中央，点击中央轮柄，桥转横向。分别访问西庭花与东庭豆科。点击中央轮柄时，角色先返回中心再转向南北。访问北庭深根，最后的阶梯解锁，登顶留下种子。

右键拖动或Q/E可以看到建筑背面的机关；按H获得方向提示。记忆不是通关门槛，十二处石碑可按兴趣读取。

## 首次玩家检查

邀请玩家在不解释解法的情况下操作。记录能否识别轮柄、可走路线、高低关系，以及角色是否被遮挡。通关后询问城市为何失败、三种植物为什么需要共同留下。当前没有形成有效的真人样本或理解率统计。

## 三维视角与新版界面

默认进入园丁跟随近景。右键拖动环绕或抬头，滚轮靠近；按V或点击右上角“总览”查看完整庭院，再切回近景。左上角目标会在转桥和升降后更新，右上角“提示”说明当前下一步，菜单中提供操作说明。悬停铜色轮柄时，物体旁会出现三维操作文字。
