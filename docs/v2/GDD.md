# 废墟里的种子 · 空中庭院 / 第二版策划

日期：2026-10-06。主题：A Gift for the Abandoned World。作品类型：原创3D建筑空间解谜。

## 这次改变了什么

第一版用终端文本和选项完成生态题材。第二版将理解过程放到建筑里：连接水路、到达日光、给不同植物留出位置。参考《纪念碑谷》的构图留白、可操作建筑和短句叙事，但设计独立的三维空间，没有复制原作素材、角色或关卡。

正交投影保持建筑插画式轮廓，右键拖动或Q/E让玩家环绕观察，滚轮调节距离。场景是真实3D；不是用截图假装立体，也不把视觉上重合的两条断路判定为连接。

## 角色与世界

玩家操纵一位带着种子的小园丁，进入被水包围的EDEN遗址。浅色石材、铜色机关、柔和穹顶仍保留旧城秩序；小范围水流、光和植物逐步恢复，表现生长的珍贵。

没有屏幕排行榜、资源答题或环境口号。居民留下的小石碑一两句话就结束。三个庭院合起来说明：快不一定能恢复、高效不一定减少需求、单一产量不能替代互补生态。

## 操作与状态

点击圆环移动。点击轮柄操作机关；角色自动沿当前可达路径走到操作点后才改变建筑。移动或机关动画中禁止其他操作。断路不能跨越；不可达时给明确提示。角色不死亡、不掉落、不需要平台跳跃。

路径是固定锚点图，边与机关朝向、升降台高度和植物收集同步。角色在桥上或阶梯上按真实三维坐标插值移动；升降台同步带角色到另一层。

## 第一庭：水之庭

| 部分 | 规则 |
| --- | --- |
| 起点 | 园丁从低层入口走到桥边 |
| 机关 | 八米长桥初始横向，与高塔断开；轮柄转90度后沿纵向连接 |
| 路径 | 入口→操作平台→旋转桥→高塔下台→真实阶梯→水源亭 |
| 完成 | 在水源亭打开水闸 |
| 反馈 | 水从高处流入低处湿地，小植物出现，第一条根的叙事卡出现 |

保留短记忆：没有收件人、河被拉直、湿地被删去、过滤与芦苇各有作用。

## 第二庭：日光庭

| 部分 | 规则 |
| --- | --- |
| 起点 | 地面路径只能到升降台下层 |
| 机关一 | 园丁走上升降台，垂直从3米升到7米 |
| 机关二 | 高处长桥初始不对齐，转桥后连接温室 |
| 机关三 | 在温室操作屋顶，两个半屋顶向两侧打开 |
| 反馈 | 植物获得日光，空城灯熄灭；可返回升降台并下降，不困住角色 |

供给预算不再是一张问答表。玩家通过到达和改变建筑，看见能源的取舍。

## 第三庭：万物之庭

| 部分 | 规则 |
| --- | --- |
| 起点 | 从水面阶梯上到中央枢纽，初始桥沿南北方向 |
| 机关 | 十米桥绕中央旋转，横向访问左右两座植物庭，纵向返回入口或进入北庭 |
| 三种生命 | 西庭花卉提供传粉者位置；东庭豆科补充养分；北庭深根稳定取水 |
| 安全性 | 从任一侧点击转桥，先走回中央，再转桥；不能把园丁留在孤立翼端 |
| 完成 | 找齐三种互补植物，北侧通往种子塔的阶梯开放 |

这是空间顺序谜题；收集互补条件后才允许登上最后阶梯，不使用隐藏数值作为答案。

## 结局

最后的手记：“不要重建EDEN”。玩家可以释放种子，让植物、根系和土地围绕旧塔生长；也可重启旧边界，种子缩在透光容器里，塔上的金色圈重新亮起。没有直接标注好坏。

玩家可继续在第三庭阅读记忆、体验另一选择、保存纪念卡。纪念卡展示选择后的庭院和短寄语。

## 内容与目标

三个原创关卡、十二处可选记忆、两个结局。目标时长8–12分钟，但当前未通过首次玩家样本验证；自动录屏时长不能替代试玩时长。

这版已实现机关动画、实际连通路径、真实高度变化、视角环绕、保存和导出。没有实现投影错觉导航、NPC、程序生成世界或实时AI叙事。后续优先做更精细的角色动作、石材接缝、植物动效与首次玩家测试。
