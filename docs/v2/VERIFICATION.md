# 第二版验证

日期：2026-10-06。环境：Apple M5、macOS、Godot 4.5、OpenGL Compatibility。

## 已执行

- 三庭实际GUI渲染，检查原色、水流、穹顶、可转视角、角色和结局截图。
- 空间测试覆盖断桥不可跨越、角色先到安全点再操作、桥模型与图边一致、真实阶梯高度、实际升降台带角色、屋顶滑开、互补植物解锁、从侧翼返回中央、两结局的容器与植物区别、记忆去重和存档恢复。
- 镜头射线验证水闸、桥轮、升降轮、屋顶轮和植物可以从可操作视角被看到，建筑遮挡不会被忽略。
- 跟随视角验证真实相机距离、角色追踪、V切换与界面状态；转桥和升降后目标即时更新。
- 新增快速移动后点击的回归：清空缓存悬停对象，在当前投影坐标点击轮柄，仍能正确走到操作点并转桥。
- 使用computer-use观察原生Godot窗口并点击试玩；这发现了点击读取旧悬停的问题。此操作不等于完整首次玩家研究。
- macOS桌面导出，并从导出的.app包启动图形模式检查；Windows交叉导出。
- 自动化未剪辑游戏游览录屏与完整视频、音轨解码检查。
- 纪念卡实际保存至验证目录，材料包校验SHA256和ZIP完整性。

最终断言计数和结果见builds/garden-tests.log，当前版本测试54项。完整日志随提交包提供。第一版28项测试只代表历史版本，不用于替代第二版验证。

## 局限

没有形成真人首次通关时间、卡点与叙事理解率数据。未验证Windows实机。没有进行系统性能基准测试，也不把电影模式的录制速度当成游戏帧率。macOS为ad-hoc签名，无Apple公证。第二版未接入真实AI服务。未上传比赛平台。
