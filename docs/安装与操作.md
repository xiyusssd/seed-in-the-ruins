# 废墟里的种子 · 1.14.0 安装与操作

macOS：直接打开 `builds/SeedInTheRuins-1.14.0.app`，或解压 `builds/SeedInTheRuins-1.14.0-macOS.zip` 后打开应用，也可拖入 Applications。双击「启动游戏.command」会优先打开新版。无需 Godot 或 Python。应用采用本地 ad-hoc 签名；已有 v4 存档可以继续。

Windows：历史试玩包为 `SeedInTheRuins-Windows.zip`，解压后双击 SeedInTheRuins.exe；此包未随 1.14.0 更新，Windows实机运行仍未验证。

WASD行走，鼠标观察，Shift快走，E/鼠标左键操作。先靠近，准星对准，按E。模块/植物先从架上拿取，再安装；取回或交换不会丢失物件。

首次进入可阅读三页电影风格全屏故事，配有BGM、海潮/温室风/枝叶环境声与翻页音效。右上「静止画面」可暂停镜头和雾尘动画，音乐继续；「继续镜头」恢复；翻页始终由你决定。开场采用生成静帧和实时推进/叠化；上一页在左下、下一页在右下、跳过在右上。第一章为新手教学关卡，在现场逐步学习移动、调查、E/F调档与伙伴协作。

C打开芽芽指令：跟随、等待、协助。它需要实际到位才能保持开关，运输任务要先取件再送达。F反向调档或取回物件，Q切换袋中种苗。Tab重读来信与调查记录，Esc打开暂停菜单；开始与暂停菜单已移除帮助入口。

六处解谜说明位于破损石碑上，文字带有凹槽、崩口与风化磨损。靠近后按 E/鼠标左键展开「残碑拓记」并收录；Tab 的记录库可以重复阅读。音乐、环境音与音效音量仍分别控制，走进温室、遮挡声源和机关修复会影响相应声音。

每章三个机关全部恢复后才能进入下一章；每章一条环境发现与三个解谜成果分别恢复1/12全局色彩。反复调查不增加颜色。两个结局都需要风塔谜题完成。

暂停菜单的设置提供鼠标灵敏度（原速度的 0.5–2 倍）、独立音乐/音效/环境音音量、高画质/兼容画质、60/120/144/不限帧率、垂直同步开关，以及重置本章。灵敏度、帧率和同步设置即时应用；实际帧率取决于硬件与显示器。切换画质会保存并重启。重置机关会让你和芽芽回到本章入口，已获得的信与颜色保留。

准星对准范围内可操作物件时出现细金色圆环。平台可以走到实际地面边缘的安全距离，斜向移动时可沿边缘滑行；石碑和机关柜会挡住玩家，水压柜已移到平台侧边。

v4存档与0.8.0的v3存档独立；新版从新旅程开始。对照版本保存在项目 builds/v8 中。

历史1.1延续1.0的v4存档；1.0对照桌面与材料包保留在builds/v10。1.1细化角色、机关与圆角网格，并将章节/档案改为宋体修复手册页面。

1.2改为工业黑体、废土建筑与同步风沙/布条/叶片/风声，延续v4存档。1.1完整对照包保留在builds/v11。1.2当时仅后台验收，未自动启动预览窗口。

1.3新增：F反向调节机关，或从插槽/种植床取回物件；Q切换袋中种苗，可以一次带上三株。Tab记录库同时保存已读维护图。水压谜题需要根据净水位规则推算，光束可以按实际装置方位观察。标题/按钮为几何中文字体，读数为等宽科技字体，正文保持清晰。1.2完整对照软件与材料保留在builds/v12。

1.4新增检修灯、水位管、接光标记与灌溉水流，开篇与来信对应修复现场，完成机关时芽芽会回应。三章界面、字号和操作字幕重新整理，保持v4存档兼容；1.3对照版本保存在builds/v13。

历史1.5（当时的帮助已在1.8移除）：探索时没有文字提示栏。Esc打开中央菜单，“帮助”集中列出全部操作；开始菜单也可先查看帮助。菜单内“随身物品”可以查看保险模块或选择袋中种苗，“来信与记录”包含最近反馈。完成本章后在菜单选择“前往下一章”，不再自动弹出完成页面。

历史1.6：首次打开先读三页插画序章，可翻页或跳过。序章结束回到开始菜单，随后开始新旅程不会立即重复播放；以后可从“旧城往事”重读。继续旅程保留原有v4进度。三章周边新增海岸住宅、海浪、分枝树木与花草；住宅目前为外景，不提供室内探索。

完成任务会自动聚焦对应变化约3秒；Esc 可结束聚焦并打开菜单，视角会回到原位置。加载已完成任务不会重复播放。
