# 1.11.1 · W-01 水路柜可达性

旧 W-01 正面朝 +Z，柜体在第一章平台的海侧边缘。平台中心为 (-3, 2.8, 5)，柜体轴心为 (-3, 2.8, 6.13)；原平台边缘到柜体轴心仅约 0.27 米，正常入口路线看到背面，无法在正面安全站立。

现在将整柜绕竖直轴转 180°，朝向 -Z，即已有平台的内侧。玩家沿入口桥走上平台后，向右转身即可看到 W-01，并对三个接头使用 E 顺转 / F 反转。无须完成任何机关或进入额外地图区域。

柜壳、铭牌、接头、刻度、箭头文字、管道、漏水和交互体积共用一个柜体坐标系。接头自身的局部旋转仍用于四档动画。工作灯架、完成状态牌和修复后的三段水流同步转向；完成水路任务的聚焦镜头移到平台内侧，仍按原逻辑返回玩家位置和视角。教程增加 W-01 的具体位置。

`w01_access_flow` 使用入口的实际第一人称角色连续执行 100 次 move_and_slide 步进，检查脚下可达性、铭牌及接头正面、三次准星射线、E/F 操作、最后一档成功触发镜头、水流侧面以及 v4 存档恢复。修改前能复现正面不可见；修改后 34 项检查通过。原九套功能检查继续执行，总计 810 项。

`w01_render_review` 使用真实 Xvfb/Mesa 光栅器，从同一入口连续走到平台，以实际玩家眼高捕捉旧版与新版。Forward+ 和 Compatibility 分别提供入口视角、黑白、1/12 复色、完整颜色，以及新版修复前后聚焦画面。完整颜色仅为渲染核对，正常新旅程仍以黑白开始。

结果石碑移到平台另一角，避免准星射线被其抢占；也检查从存档平台点返回后的三个操作目标。
