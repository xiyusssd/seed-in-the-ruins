# 1.7 废土界面与模型检查

界面以旧城的维护设备和保管档案为依据：氧化绿金属、暗锈、黄铜操作件、磨损纸张。标题与按钮使用站酷庆科黄油体的窄体字形，正文使用Noto Sans SC，刻度与键位使用Share Tech Mono并提供中文回退。故事、来信、设置、帮助、物品、暂停和结局共用同一套风格。

铆钉和划痕留在面板边缘，正文区域保持干净。按钮有明确的悬停、按下和键盘焦点状态。菜单始终居中，小窗口可滚动；探索界面仍只有准星和菜单按钮。菜单位于复色滤镜上方，保留纸张和锈迹的颜色，世界继续按线索逐步复色。

## 模型与材质修正

- 住宅门板、木窗框使用木纹贴图；温室和回生花园的种植床使用泥土贴图；废旧管道、栏杆、棚顶使用锈钢贴图。三者不再共用混凝土纹理。
- 27张三维图片显式配置mipmap与显存压缩，法线贴图使用正确的法线导入选项；建筑材质使用斜视过滤。
- 扫描树枝统一贴图UV与法线切线的来源，保留原有UV缩放和偏移；修正实际Forward+截图中的枝条黑块。海面降低人工天空混色与镜面强度，提升粗糙度，保留波浪、岸边泡沫和真实天空反射。
- 原创植物补充叶片UV、叶脉、色差与透光；叶尖退化三角形移除，叶面法线按曲率计算。
- 海岸草丛改为从地面长出的三叶弯曲草簇，替换平铺的椭圆叶片。环境光保留天空照明，并混合少量冷色填光，提高墙面和树冠在阴影中的可读性。
- 芽芽外壳使用磨损搪瓷，漆面磨损由连续噪声计算，避免硬方格颗粒。原有镜头、履带、机械臂与关节继续保留。
- 房屋、岩岸、树冠、海面、泵房、温室、种植床、旋转桥、升降台、管道、镜架、风塔、机器人、种子台、保护罩与再生植被均列入渲染检查；同时检查初始与修复后的模型资源。

32份外部资源的来源与SHA256位于 `game/assets/scenery/SOURCES.json`。两份扫描模型的全部顶点、法线与UV通过有限值检查，记录在 `builds/v17-scan-geometry-audit.json`。

## 光照加强

日光角度降低，暖色主光与冷色环境光形成层次，保留四级联日光阴影。泵站的维修灯、温室的照明、回生花园的风塔灯均有实际灯具、光源和受控发光材质；机关修复后才通电。芽芽的镜头增加局部柔光。高画质使用小范围体积雾接收光照；兼容画质保留光源和材质，省去体积雾。泛光只响应高亮灯具，减少天空和地面的整体泛白。

海面同镜头对照确认屏幕空间反射会产生远处的块状亮斑，已关闭该效果，继续使用天空与反射探针。温室旧黄色圆柱光效移除；保护罩改用玻璃材质，其装饰碰撞始终关闭，避免隐藏时阻挡最后的种子交互。

灯光、雾层和泛光设置依据[Godot 4.5 Environment](https://docs.godotengine.org/en/4.5/classes/class_environment.html)、[Light3D](https://docs.godotengine.org/en/4.5/classes/class_light3d.html)和[FogVolume](https://docs.godotengine.org/en/4.5/classes/class_fogvolume.html)的接口。检查镜头切换时关闭雾层历史累积，游戏运行时保留引擎的时间重投影。

## 后台实景检查

遵照“不要跳出来”，检查使用Docker内的Xvfb虚拟显示。Godot的Forward+通过Mesa软件Vulkan实际绘制，兼容画质通过软件OpenGL绘制；不是Godot headless的空渲染器。运行中不启动、聚焦或弹出macOS游戏窗口，也不访问玩家的真实存档。

截图镜头和修复状态为受控视觉检查，不能作为实际通关或原生GPU帧率的证据。真实九个谜题、伙伴协作与十二条线索的流程由独立的 `puzzle_flow` 测试检查。原生macOS Metal画面和Windows实机表现仍需各平台验证。

两种画质各42张实景图，共84张；每种画质记录初始与修复状态的模型、材质和灯光信息，数量见对应清单。六套逻辑与界面测试共452项通过。

实际截图、逐节点材质清单与日志保存在 `builds/render-iterations/v17-final/{forward_plus,gl_compatibility}`。完整图库为 `builds/visual-board.html`。检查工具会拒绝空渲染、缺失材质、非法顶点、空白图像或不正确的0/50/100%复色结果。

资源检查不能代替画面检查。第一轮模型清单虽通过，实际截图仍发现扫描细枝的黑块；材质分组对照将问题定位到枝条法线使用的UV与切线不一致。修正后通过相同镜头对照、完整场景重渲染与UV/切线回归检查。历史第一轮图片保留在 `builds/render-iterations/v17-first-pass`，后续材料检查保留在 `v17-material-pass`，光照迭代保留在 `v17-before-lighting` 与 `v17-lighting-pass`，均不作为最终合格画面。

Apple Silicon开发机上的复现命令：

```sh
mkdir -p .tools/render-background
curl -fL https://github.com/godotengine/godot-builds/releases/download/4.5-stable/Godot_v4.5-stable_linux.arm64.zip -o .tools/render-background/godot.zip
docker build -f tools/render-background.Dockerfile -t seed-render-review:4.5 .tools/render-background
python3 tools/render_background.py --method forward_plus
python3 tools/render_background.py --method gl_compatibility
python3 tools/check_render_review.py
python3 tools/review_board.py
```

三维纹理导入配置依据[Godot 4.5图像导入文档](https://docs.godotengine.org/en/4.5/tutorials/assets_pipeline/importing_images.html)。源码包保留 `.import` 配置，避免重新导入时丢失mipmap、法线与模型LOD设置。

软件交付为1.7.0版本独立app、macOS安装包、Windows交叉导出包和源码。`package_release.py` 要求逻辑测试、两种实际渲染检查和像素检查完成后才打包。1.6.1的安装包保存在 `builds/v161`，旧版本app继续保留。
