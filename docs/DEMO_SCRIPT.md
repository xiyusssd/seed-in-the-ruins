# 1.0 演示与录像

先展示初始黑白和芽芽，读第一封环境来信。观察水路维护图，旋转三段接头；看到漏水停止，桥解锁。走桥去滤池，按刻痕调阀；请芽芽守住踏板，再到泵房启动。

第二章查看方、圆、三角槽位，从物件架拿模块安装。走进通电的日光台，上层观察镜架图与分段光束。调整两面镜子，让芽芽保持制动，玩家打开屋顶。

第三章按访客、养分、深水记录安排三个植物，再按水量刻痕分配。去风塔，让芽芽回工具架取储能单元并送达，接通两段根系。展示风塔转动与全彩，最后展示保护罩/自由生长两种选择。
