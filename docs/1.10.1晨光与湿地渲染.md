# 1.10.1：建模后的晨光与湿地渲染

继续使用 1.10.0 重建的临水宫楼、钟楼、山体、温室格架和回生花园拱廊，调整整个可玩场景的光照和表面。没有用开场图替代游戏视角。

## 本次画面变化

- 既有 CC0 HDR 天空在运行时降低蓝色饱和度，背景与天空光照共用同一材质；侧后方低角度晨光照亮建筑轮廓、雨水和叶缘。
- 远景恢复后仍保留海岸薄雾，恢复前雾更浓。高画质模式保留体积雾、环境遮蔽、间接光和局部工作灯。
- 铺石保留原始颜色、法线与粗糙度贴图，降低表面粗糙度并加入原生 clearcoat 雨膜。码头增加不规则积水，波纹和边缘由着色器计算。
- 海面降低粗糙度，捕捉附近真实建筑、地形和天空的立方体反射。海水和积水从反射相机中排除；静态探针覆盖近海，并等待六面反射捕捉完成后检查画面。
- 叶脉高光和叶片背面透光增强，保留现有风、叶片网格及原始纹理。
- 低机位暴露的十四块旧方形岸堤改为侵蚀岩岸，表面不规则，底部继续深入海面以下。

## 验证与交付

功能检查共 **629 项**：菜单 54、第一人称 56、解谜 266、可玩路线 37、废土表现 36、场景 126、教学 22、音频动画 32。完整实际渲染为 **152 张**：Forward+ 与 Compatibility 各 76 张，保留上一版 74 个镜头，新增海岸低机位与温室晨光镜头。固定镜头对照会核对相机位置、目标和画幅。

实际图与验证记录位于 `builds/render-iterations/v1101-final/` 和 `builds/v1101-*.json`。完整画廊为 `builds/visual-board.html`，交互对照为 `builds/render-comparison-1.10.1.html`。功能检查、像素检查、16 张材质源图和原CG哈希核验通过后打包。

三章的本版材质及原生网格快照放在 `models/1.10.1/`。建筑重建元数据仍为 1.10.0，渲染材质档案为 1.10.1。快照来自真实光栅渲染场景；保留显式网格、UV、法线、变换与实例缓冲，只移除 Godot 保存时产生的冗余继承场景声明。保存后重新加载三章网格检查几何有效性与资源释放。

快照包含 CinematicRuins 建筑、码头与植物。完整水面、侵蚀岸堤、解谜和灯光由游戏工程一起构建，运行入口为 `game/garden.tscn`。macOS 预览为 `builds/SeedInTheRuins-1.10.1.app`，完整源码与模型打包在本版 Source.zip。上一版安装包、源码和哈希保留在 `builds/releases/1.10.0/`，上一版实际图保持不变。

## 检查范围

图片由 Godot 4.5 在 Docker/Xvfb 中使用 Mesa 软件 Vulkan/OpenGL 产生，验证实际场景，不能代表原生 Metal 的驱动表现或 GPU 帧率。macOS 导出后另做原生应用场景加载、签名、DMG 和包哈希检查；Windows 为交叉导出，未在 Windows 上运行。

立方体反射是从固定点采集的近似，适用于静态建筑；不是精确平面倒影。引擎采集与更新方式见 [Godot 4.5 ReflectionProbe 文档](https://docs.godotengine.org/en/4.5/classes/class_reflectionprobe.html)。新增镜头的构图和空间比例仍与开场 CG 不同。画面更接近阴云、晨光与湿海岸气氛，尚未达到 CG 的摄影细节。
