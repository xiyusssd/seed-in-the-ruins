# 1.8.4：岩岸、浅水与草丛

2026-10-10。本轮继续完善实时三维海岸场景，沿用1.8.3的生成材质、现有CC0树木/岩岸扫描与原创植物。没有新增外部素材或生成图片。

## 场景改动

四栋海岸住宅的18段竖直多边形基座改为96段连续轮廓、五圈土层网格。建筑下方保持平缓地面，外缘逐步下沉到水下；湿润边缘采用顶点色，土层用已有土壤颜色/法线/粗糙度纹理。每栋住宅增加130块实例化岸石，保留原有岩岸扫描。

每栋住宅有两片椭圆草丛，共390簇。五片弯曲叶片组成一簇，混合高矮、疏密、枯黄与绿色，沿用统一风场和生成叶脉。草丛关闭独立阴影，岸石和房屋继续受光；碎石以MultiMesh批量提交。

海水与土层使用同一个连续岸线公式，修正原来泡沫轮廓与地形各算各的偏差。近岸增加浅水颜色过渡、细碎泡沫，双方向细浪受不规则扰动；远处微细纹理按像素覆盖范围渐隐。这里的浅水带是美术遮罩，没有模拟真实水深或流体。

住宅仍为外景，沿用原来的机关、行走区域和碰撞。三章都使用这些海岸细节；全局十二次复色继续工作。

## 验收材料

八套功能检查557项通过。新增的地形检查验证上表面法线朝向、下方延续到水面以下；三章解谜、伙伴协作、教学、存档、菜单和声音/动画回归通过。详见 `builds/v184-test-summary.json`。

完整画面验收包含Forward+与Compatibility各58张截图，新增土层岸缘、浅水、草丛与近水细浪镜头；模型材质/顶点审计、黑白/半彩/全彩像素检查随截图执行。最终通过结果以 `builds/v184-render-pixel-verification.json` 和 `builds/v184-material-verification.json` 为准。

截图在Docker/Xvfb虚拟显示和Mesa软件GPU中渲染，可判断本轮图像和模型质量，不代表本机Metal驱动帧率。macOS导出后另验签名及场景加载；Windows只交叉导出，仍待实机运行。
