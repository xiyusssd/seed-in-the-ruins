# 1.1 · 旧城修复手册与模型细化

2026-10-08。在1.0九个谜题与芽芽协作的基础上提升近景结构、字体层级与界面组件，保持v4存档兼容。

## 近景模型与材质

- 原创圆角箱体网格：六面网格投射到圆角表面，显式平滑法线、按尺寸与半径缓存。用于机器人和机关柜的外壳；可见细节不增加路线碰撞。
- 芽芽：分层镜头环与玻璃、小光瞳、检修面板、螺栓、通风槽、分段履带、颈部与机械臂关节、夹爪；背部独立种子盒与运输储能单元分开。保留单镜头、双履带的原创维护机器人设计。
- 机关：圆角搪瓷机柜、嵌入面板、顶盖与铭牌、固定螺栓、底座、方向刻度、控制轴；较粗管道增加两端法兰。
- 原创世界坐标磨损材质表现细小掉漆与浅条纹；没有导入第三方模型、纹理或照片。
- 高画质减弱辉光并调整接触层次，保持第一人称谜题细节清楚。

## 字体与组件

Noto Serif SC的600字重用于标题、400字重用于故事；Noto Sans SC的600字重用于操作、450字重用于说明。两套字体均附SIL OFL许可。

章节、档案、提示和结局采用米色纸页与墨色文字；菜单与伙伴指令使用深色机械面板，铜色边框、明确主按钮、鼠标悬停和键盘焦点反馈。探索界面显示当前目标、十二条复色刻度、章内三个机关状态和伙伴当前动作。音量滑块与画质按钮统一外观。第一人称使用屏幕交互提示，取消重复的大型悬浮交互文字。

截图新增伙伴面板、维护记录、逐级提示和设置页，收录在visual-board.html。两种渲染器分别保存同视角截图与源码快照；数据与实际验收记录见VERIFICATION.md。
