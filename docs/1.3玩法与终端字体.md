# 1.3 · 把时间留给观察与协作

2026-10-08。保留三章九个谜题、十二条复色线索与两种结局。在1.2废土场景基础上改善重复折返、单向转档和维护记录难以复查的问题。

## 操作与反馈

- 种苗袋有三个位置，可在入口一次带走三株。Q选择，E种植或交换，F取回。种下后选择下一株；取回或交换不会复制或吞掉物件。保险模块仍使用单物件操作。
- E正向、F反向调节管道、阀门、镜架、分水器和根系，每次一个明确档位。机关旋钮和镜架有0.18秒短动画；操作仍需亲自接近并用准星对准。
- 已读维护记录自动存入Tab记录库；未读的记录不会凭空出现。读取和复查不增加颜色，机关重置保留观察到的记录。
- HUD提供工作地点与实时仪表反馈。漏水指向尚未接通的一段；水位偏高/偏低及阀门刻痕分别判断；镜架显示中继是否收到光；错误种植有缓慢生长反馈；分水器显示欠水、过量或到线。
- 水压说明改为净水位计算与回流刻痕，让玩家推算进水。中继板有实际模型，第一镜架向东、中继到第二镜架、第二镜架向西到幼苗的布局与刻度图相符。主动查看三级提示仍可获得完整操作解法。

通关流程改为一次从架上拿齐种苗，依次走过西、东、北床；不需要为了每株植物再次穿桥回到入口。桥梁仍需亲手调整，也继续服务后续灌溉探索。没有新增限时失败、战斗或死亡惩罚。

## 字体与终端界面

站酷庆科黄油体用于中文标题和按钮，Share Tech Mono用于终端索引、数字读数和状态；中文读数回退到Noto Sans SC。正文使用Noto Sans SC，避免长篇阅读被装饰字体干扰。采用旧铜、灰绿与煤灰，设备记录、提示和指令为暗色维护终端，章节与来信仍保留温暖纸页。

字体原始文件来自[Google Fonts的ZCOOL QingKe HuangYou目录](https://github.com/google/fonts/tree/main/ofl/zcoolqingkehuangyou)和[Share Tech Mono目录](https://github.com/google/fonts/tree/main/ofl/sharetechmono)，SIL OFL完整文本随两平台安装包附带。未修改字体文件本身；Godot资源配置回退与字距。
