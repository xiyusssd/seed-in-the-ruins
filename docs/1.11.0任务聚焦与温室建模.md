# 1.11.0：任务聚焦与温室建模

九项任务完成后，镜头用 0.65 秒移向对应设备或花床，停留 1.6 秒（开顶及最终修复 2.2 秒），再用 0.65 秒返回原视角。结果面板说明具体变化；Esc 立即完成视觉变化并返回菜单。玩家坐标、鼠标朝向和存档坐标保持原值。

状态仍由原来的 puzzle v4 存档提供；加载已完成任务会直接还原对应景物，不重播镜头。失败操作和重复完成不触发聚焦。返回标题、打开面板、切换章节和受控渲染都会释放镜头控制；连续成功事件按顺序呈现。新水流、蓄水池和植被都是三维场景节点，无新碰撞和交互遮挡。

温室增加 16 个落地陶盆、六个由钢索悬挂的木质吊篮、支柱藤蔓与 24 根钢肋。原大支柱接入灰泥材质；右侧破损顶棚加入局部暖采光与低透明度光片。植物继续使用弯曲网格、实例化叶片和既有原始材质图。新增育苗区低视角镜头更便于比较近景层次。

## 检查与产物

功能检查 776 项，其中聚焦反馈专项 125 项，覆盖九项真实成功操作、镜头归还、精确视角/FOV恢复、存档、失败与重复操作、退出、切章及排队。Forward+ 和 OpenGL Compatibility 各 98 张实景：保留前版 78 个镜头，新增育苗区、九项任务修复前后及实际早期复色状态共 20 个镜头。修复对照保持相同相机、画幅及复色状态。

原生模型保存在 models/1.11.0，包含本版静态温室育苗、吊篮、钢肋、藤蔓及晨光光片，三章全部重新载入验证。实际修复景物、镜头与局部灯光在完整 game/garden.tscn 中构建。原始生成的 16 张材质图、开场图和音频保留原始指纹；没有新增 AI 图像。1.10.2 安装包和源码归档于 builds/releases/1.10.2。

实景与任务对照在 builds/render-comparison-1.11.0.html，完整图库在 builds/visual-board.html。图片由 Godot 4.5 / Docker / Xvfb / Mesa 软件 Vulkan、OpenGL输出。macOS另验证原生场景加载、本地签名与DMG；Windows为交叉导出，未实机运行。镜头与植物已加强，但现有功能平台的比例、光照细节与原开场CG仍有明显差距；固定立方体海面反射也仍是位置近似。
