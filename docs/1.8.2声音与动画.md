# 1.8.2 声音与动画

2026-10-10。序章、标题和菜单使用独立声轨，解决故事覆盖场景时章节声音暂停造成的安静开场。三页共用51.2秒原创主题，翻页保留乐句位置；海潮、温室风和枝叶环境声约0.5秒渐变，跳过/进入旧城配独立音效。探索时序章主题逐渐退出，两层章节配乐恢复；世界机械声随真实空间位置与机关状态变化。

配乐为75 BPM、16小节，使用阻尼泛音、柔和铺底、稀疏高音旋律与立体声反射合成。三章分别安排不同和声和旋律，基础/复苏层共享长度和节奏，恢复机关与颜色时复苏层增加。所有声音遵守音乐/音效/环境三条音量控制，设为0时分别静音；未改变用户音量设置或保存路径。

序章加入缓慢雾气、微尘、芽芽镜头呼吸光和分段渐显的文字。静止画面冻结这些运动，仍可翻页叠化，音乐继续播放。照片建筑边缘没有扭曲，仍是生成静帧配实时镜头/光效。芽芽的52片履带按实际行走距离沿封闭带环滚动；停止和暂停时保持原位。近处注视玩家、抬臂协助和庆祝动作平滑衔接，机关判定与寻路规则保留。

代码入口：`soundscape.gd`、`story_film.gdshader`、`story_vignette.gd`、`robot_companion.gd`。音频合成：`tools/make_cinematic_audio.py`。源码声轨校验：`tools/check_audio_review.py`。实际引擎混音：`builds/render-iterations/v182-audio/gl_compatibility/audio-mix-preview.wav`，含三页序章、标题、三章和翻页声采样，末段为全静音检查。

验收说明见 `docs/VERIFICATION.md`，实渲和混音图库在 `builds/story-review.html`。后台软件渲染与Dummy驱动的DSP混音证明播放链路，不等同于本机扬声器听感或原生GPU帧率；Windows包仍为交叉导出。
