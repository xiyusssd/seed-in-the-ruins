# 1.8.3：内置画面生成用于三维材质

2026-10-10。工具：内置 `image_gen.imagegen`，未调用外部API或下载图片。生成七张1254×1254 PNG，原图直接复制进游戏，无后期图像编辑。

灰泥用于海岸住宅墙体；混凝土用于庭院地面、桥面和风化结构。各组使用原生StandardMaterial3D，颜色/法线/粗糙度分别采样，2.5米世界坐标三平面映射，法线强度0.22/0.18，Mipmaps和各向异性过滤。实际建筑保留窗洞、阳台和曲面屋瓦；材质没有改变碰撞、机关或可走区域。

叶脉用于原创曲面叶片与草簇，通过亮度细节保留每种植物原有色调；花瓣保持原有颜色，扫描树叶仍用自己的配套纹理。草叶继续随风运动，叶片背光保留。

法线和粗糙度由生成工具参考颜色图估计，不能保证像测量扫描一样逐像素精确，也没有生成可编辑三维模型。材质拼接与视觉质量以实际引擎近景为准。粗糙度以红通道采样；法线用引擎专用线性导入和重建，避免蓝色数据被当成颜色。

## 实际验收

八套功能检查549项通过，新增真实材质绑定、七个资源哈希和叶片纹理连接检查。Forward+与Compatibility各54张截图，包含三章、修复前后、0/50/100复色、教学、全屏/小窗故事与三个材质近景；模型材质和顶点检查随每章执行。后台Docker/Xvfb软件GPU验证图像，不代表原生Metal帧率；Windows仅交叉导出。版本保留1.8.2原有CG、音效、BGM和动画，音频资产与声音脚本的指纹继续匹配上一版。

实景图库：`builds/visual-board.html`；像素及源码指纹：`builds/v183-render-pixel-verification.json`；素材通道与来源验证：`builds/v183-material-verification.json`。
