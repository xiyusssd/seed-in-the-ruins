# 废墟里的种子 · 1.0 游戏设计

第一人称治愈废土环境解谜，原创维护机器人芽芽与玩家协作，三章九个谜题、十二条复色成果、两个结局。详细决策、答案与状态行为见 [1.0解谜设计](1.0解谜设计.md)。

核心循环：观察3D场景与维护记录，拿取或调节机关，观察错误反馈，派机器人协作，让废墟恢复运转。所有规则依靠形状、方向和刻痕，开场纯黑白也可辨认。

第一章修复水路、水压和水泵；第二章匹配模块、引导日光和同步开顶；第三章安排植物、水量分配、接通根系与储能风塔。完成当前章三个谜题才能前进；不是只走到终点或点击结果石碑即可过关。

玩家连续WASD行走，鼠标观察，E操作，C伙伴指令，H三级提示，Tab来信册，Esc暂停与设置。第一人称眼高1.65米、视野76度，真实桥梁、阶梯、升降台。机关错误可纠正，物件交换可逆；无死亡、无解谜限时惩罚。

每章一封环境信与三份解谜成果，共十二条，每条为全画面恢复1/12颜色，2.4秒过渡；重复不增长，存读档与章节切换保留。两个结局改变保护罩与自由生长形态，均需九个谜题完成。

首次人工游玩目标30–45分钟，尚无首次试玩时长验证。自动化镜头知道解法，只用于通关与交互检查。早期版本文档保留在v1/v2目录，0.8.0完整材料在builds/v8。
