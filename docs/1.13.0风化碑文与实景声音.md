# 1.13.0 · 风化碑文与实景声音

六处解谜提示改为残碑。石片具有约 30 厘米厚度、不规则破口、风化倒角、裂缝和碎裂石脚，原来整洁的纸面、金属架与牌面分隔线撤下。水压碑移到平台西侧并增加碎石基座，让水位规则避开仪表管与楼梯的遮挡。

碑文由原始提示文字及随项目附带的 Noto Serif SC 字体生成六张标量深度图。逐字轻微偏转和偏移、切削深浅、缺损和侵蚀共同打断整齐的笔画；材质依据深度梯度生成凹槽的表面法线，随真实场景灯光受光，石材颗粒穿过磨损处。它属于材质浅浮雕，没有对每个汉字进行石块布尔切割。`tools/make_stele_inscriptions.py` 可重建资产，文字、字库校验值和生成方式见 `game/assets/inscriptions/manifest.json`。场景保留隐藏的文字布局节点用于测量，实际画面中的字来自石材深度图。

方向箭头、模块外形、水位档位和全部规则均沿用原文；E/左键打开「残碑拓记」全文，Tab 重读，沿用 v4 存档。收录碑文仍不会直接授予解谜成果。

建筑细化包括：泵站和温室的曲面石柱分块、错缝砌筑，泵站拱券与立柱接缝，温室 U 形檐沟、管箍、弯头与排水格栅，花床边缘碎石与落叶。新增几何为视觉细节，主体道路、碰撞与机关保持原有路线。桥面和升降机踏面采用锈钢材质，与金属脚步对应。

渲染调节包括：干石材降低清漆强度、保留原始颜色/法线/粗糙度图；玻璃加入细小残留雨滴和掠射角变化；水洼采用衰减环形涟漪与远处滤波；日光、接触阴影和复色雾量调整。温室使用限定范围、排除水面的局部反射捕捉。兼容画质仍采用自身的光照效果。

声音使用 14 份新原创合成资产：6 条不同长度的风、海潮、水渠、滴水、枝叶、水泵循环，石面和金属各 4 次脚步。它们是周期滤波噪声、阻尼共鸣与非均匀事件合成，没有使用野外实录。生成脚本是 `tools/make_realism_audio.py`，来源和校验值是 `builds/v113-audio-assets.json`。

海潮、灌溉、滴水和枝叶采用实际世界位置的单声道声源，距离、左右方向和静态碰撞遮挡决定音量和高频。泵和水流随谜题修复开启；温室与泵站内外边界平滑改变环境声和短混响；走路依据真实位移、踏面和轮换录次触发。音乐降低基础音量，环境细节更容易被听见。新增声音经过原有音效/环境父总线，音量与静音继续生效。遮挡是一条碰撞射线加低通，室内反射是区域混响，尚非全波声学模拟。

本机 Apple M5 使用真实 Metal 3.2/Forward+ 与 OpenGL 4.1/Compatibility 渲染。九个场景镜头与 1.12.3 同机同姿态比较，另在六处实际可站立位置各拍碑文与全文，两种画质都检查黑白可读性、E 交互和归档。原图及引擎报告见 `builds/realism-native`、`builds/realism-compatible`、`builds/stele-native`、`builds/stele-compatible`。图库为 `builds/realism-review-1.13.0.html`。这是实时引擎实景截图，没有用生成图替代游戏画面。

功能回归、引擎立体声混音、导出应用、签名及资源校验结果分别记于 `builds/v1130-test-summary.json`、`builds/realism-audio/realism-audio-audit.json` 和 `builds/realism-release-verification.json`。声音试听为引擎 AudioEffectCapture 的输出，含三章环境与脚步、左右声源、距离和静音片段。

Godot 接口依据：[AudioStreamPlayer3D](https://docs.godotengine.org/en/4.5/classes/class_audiostreamplayer3d.html)、[Environment](https://docs.godotengine.org/en/4.5/classes/class_environment.html)。
